# Java basics

Java fundamentals and object-oriented basics.

| Folder / file | Covers |
| --- | --- |
| `Array/` | array helpers, user input |
| `Inheritance/` | method overloading and overriding |
| `Threads/` | creating threads, constructor references |
| `Cards/` | a small card game: `Card`, `Deck`, `player`, `Main` |

Run a file with `javac Main.java && java Main`.
